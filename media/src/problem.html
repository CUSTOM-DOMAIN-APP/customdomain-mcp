The problem

Customers don't know where their domain lives.

Over 100 providers can hold a domain. Most people can't say which one holds theirs, so connecting it to your app turns into a support ticket.

The customer
I want to use my own domain with your app. It says to add DNS records, but I don't remember where I bought it.

100+places a domain can live
Registrars, DNS hosts, website builders, hosting companies and cloud platforms. Each with its own screens and names.
The manual route
  1. Work out which provider holds the domain
  2. Log in, if you remember how
  3. Find the DNS settings, which every provider names differently
  4. Add a CNAME and a TXT record exactly as written
  5. Mind the Name field and the trailing dot
  6. Wait, check again, and hope
The result: stalled setups and support tickets, for something that should take a minute.
