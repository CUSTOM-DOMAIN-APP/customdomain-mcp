CustomDomain™
API and SDK

One integration for every customer's domain.

Mint a token on your server, call open(), and the widget does the rest. Or drive the same flow from the API.

your-app.ts
// On your server: POST /v1/tokens
// (never ship an API key to the browser)

import { customdomain } from "customdomain-js";

customdomain.open({
  applicationId: "app_123",
  token: tokenFromYourServer,
});

// Hear when the domain is connected
window.addEventListener("customdomain:success", (e) => {
  console.log("connected:", e.detail.domain);
});
